# Echo 0.13.0

Account sign-in, registration, email password-reset requests, direct/recovery password updates, profile saves, avatar changes, sign-out, account refresh and deletion now detach the popup content while processing. A focused, live status region shows a spinner. Actual completion shows a check or cross, localized message and explicit continuation button. The registration result directs the user to confirm the email link; reset requests retain the conditional response that does not reveal whether an email is registered. No fake progress or timed success is used.

Failed operations restore the original form nodes on Back to retry. Email/code drafts and generation request identifiers remain in page memory; password fields are cleared. A closed or replaced popup, changed account or departed admin tab cannot be reopened by an old completion. Successful sign-out discards the private profile snapshot and clears the temporary email draft. Feedback supports both themes, English/Chinese, keyboard focus, aria-live/busy, and reduced motion.

Settings and the account page provide one Administration entry. Its full-page URL uses #admin=members or #admin=codes. The shared tabs contain the existing member editor and code tools; no administrator record is presented in the popup. Back/Forward, direct URL restoration after authentication, and role-based access guards are supported. Switching sections leaves music playback untouched. An expired session or account switch clears private admin data, and the server remains the authority for every operation.

The active Sheets/App Script version 5 endpoints and schema are unchanged. Tests cover deferred requests, exact pending/success/error states, retry drafts, cleared passwords, email instructions, language changes, late responses, private data clearing and browser navigation. No real registration, email, membership grant or other user's data was changed during verification. This environment has no supported browser-preview helper; physical mobile layout and device playback are not visually verified.
